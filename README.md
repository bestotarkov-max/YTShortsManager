## 🚀 О программе

**YT Shorts Manager** — это полноценное десктопное приложение для скачивания видео и Shorts с YouTube. Программа имеет современный темный интерфейс, работает в системном трее, умеет обходить современные блокировки и обновлять сама себя.

В отличие от многих аналогов, приложение **не требует** установки Python, Node.js или дополнительных библиотек. Всё уже упаковано в один ZIP-архив.

## ✨ Основные возможности

*   📥 **Скачивание в высоком качестве**: Поддержка видео до 4K, 1080p, 720p. Всегда со звуком.
*   🧠 **Умный буфер обмена**: Просто скопируйте ссылку на видео (Ctrl+C), и программа сама извлечет её из текста и вставит в поле.
*   📋 **Очередь загрузок**: Добавляйте несколько ссылок подряд, программа скачает их по очереди.
*   ✂️ **Встроенная обрезка**: Скачивайте только нужный фрагмент видео.
*   🎵 **Только звук**: Возможность извлечь аудиодорожку в формате MP3.
*   🌐 **Интеграция с браузером**: Скачивайте видео в один клик прямо со страницы YouTube (через встроенное расширение).
*   📜 **История и обложки**: Удобный список всех скачанных файлов с превью. Клик по видео открывает его в вашем плеере.
*   🌍 **Два языка**: Полная поддержка русского и английского интерфейса (RU / EN).
*   🔄 **Автообновление**: Программа сама проверяет новые версии на GitHub и обновляется в один клик.
*   🧹 **Очистка кэша**: Удаление временных файлов и истории.

## 📥 Установка и запуск

1.  Перейдите в раздел **[Releases](https://github.com/bestotarkov-max/YTShortsManager/releases/latest)**.
2.  Скачайте последний **ZIP-архив** (например, `YTShortsManager_v1.3.1.zip`).
3.  Распакуйте архив в любую удобную папку (например, на Рабочий стол).
4.  Запустите файл **`YTShortsManager.exe`**.
    *   *Если Windows покажет синее окно защиты (SmartScreen), нажмите «Подробнее» -> «Выполнить в любом случае».*
5.  Программа свернется в системный трей (возле часов).

> ⚠️ **Важно:** Не удаляйте файлы `yt-dlp.exe`, `ffmpeg.exe` и `deno.exe` из папки с программой. Они необходимы для скачивания, звука и обхода защиты YouTube.

## 🌐 Установка расширения для браузера (Опционально)

Чтобы скачивать видео в один клик прямо с сайта:
1.  Откройте браузер (Chrome, Яндекс, Edge).
2.  Введите в адресную строку `chrome://extensions/`.
3.  Включите **«Режим разработчика»** (справа вверху).
4.  Нажмите **«Загрузить распакованное расширение»**.
5.  Выберите папку `yt-bridge-extension` (лежит внутри папки с программой).
6.  Зайдите на YouTube, обновите страницу (F5). Возле кнопки «Поделиться» появится синяя кнопка ⬇️.

## ❓ Решение проблем (FAQ)
*   **Порт 5000 занят:** Если при запуске возникает ошибка «Порт уже используется», закройте все копии программы через диспетчер задач. В версии 1.4.0 порт освобождается автоматически при выходе.
*   **Не определяется длительность видео:** Убедитесь, что вы авторизованы в YouTube в браузере — расширение передаёт cookies, чтобы программа могла получить данные о возрастных видео.
*   **Видео скачивается без звука:** Убедитесь, что файл `ffmpeg.exe` не был удален и лежит рядом с программой.
*   **Ошибка 403 или «Сбой yt-dlp»:** Нажмите кнопку **«⬆️ Обновить yt-dlp»** в программе. Разработчики `yt-dlp` часто выпускают патчи безопасности.
*   **Антивирус ругается:** Из-за того, что программа собрана самостоятельно, антивирусы (включая Defender) могут ложно срабатывать. Добавьте папку в исключения.
*   **Не работает кнопка в браузере:** Убедитесь, что программа запущена (иконка в трее) и расширение включено.

## 🔄 Надёжное автообновление

Полностью переписана установка обновлений — исправлена ошибка, из-за которой после обновления программа «пропадала» или появлялась папка новой версии внутри старой.

- **Определяется реальный корень архива.** Если ZIP упакован «папкой» (как при обычном сжатии в Проводнике), обновление берёт файлы из вложенной папки, а не создаёт её внутри установочной.
- **Проверка до изменений.** Если в архиве нет `YTShortsManager.exe`, обновление отменяется, а текущая версия остаётся нетронутой.
- **Обязательная проверка SHA-256** скачанного архива. Несовпадение хэша — обновление блокируется с понятным сообщением.
- **Защита от zip-бомб**: лимит на количество записей (20 000) и распакованный объём (2 ГБ).
- **Ожидание по PID** вместо фиксированной паузы: установщик ждёт фактического завершения приложения (до 2 минут).
- **Старая версия не удаляется, а переименовывается в `.old`** — это работает даже для запущенного файла.
- **Повторы копирования и запуска** на случай блокировки антивирусом или файловой системой.
- **Автоматический откат при любой ошибке**: возвращается прежний `exe`, затем показывается окно с описанием проблемы и путём к логу.
- **Проверка запуска новой версии**: если она завершилась сразу после старта, выполняется откат.
- **Подробный лог обновления**: `%LOCALAPPDATA%\YTShortsManager\update.log`.
- **Аккуратная уборка**: после успеха удаляются `update_temp`, `update.zip`, `.old` и сам скрипт обновления.
- **Пользовательские данные не затрагиваются**: `config.json` и `history.json` сохраняются.
- **Проверка доменов загрузки**: обновление скачивается только с доверенных хостов GitHub по HTTPS.
- **Валидация версии и ссылки** из `version.json` перед скачиванием.

## 🔐 Безопасность

- **Куки и логи перенесены в `%LOCALAPPDATA%\YTShortsManager`** — больше не хранятся рядом с программой.
- **Временные файлы куки** создаются с уникальными именами и удаляются после использования; при старте выполняется очистка «осиротевших» файлов.
- **Проверка `Origin` для HTTP-моста**: запросы принимаются только от расширений Chrome/Firefox.
- **Ограничение тела HTTP-запроса** — 2 МБ, защита от переполнения памяти.
- **Лимит очереди загрузок** — 30 элементов; при переполнении возвращается `429 queue_full`.
- **Санитизация истории**: обложки принимаются только с `https://img.youtube.com`, заголовки обрезаются до 300 символов, хранится не более 50 записей.
- **Лимит кэша информации о видео**: 200 записей, TTL 30 минут, не более одной операции `yt-dlp` одновременно.
- **Ротация лога** при достижении 2 МБ.
- **Глобальный обработчик исключений UI**: ошибка интерфейса больше не закрывает программу молча — она пишется в лог.
- **Защита от повторного запуска** через именованный мьютекс.
- **Валидация настроек**: битый конфиг не роняет запуск, путь загрузки приводится к корректному.

## 🛠️ Сборка и релиз

- **`build.ps1`**: исправлена проверка содержимого ZIP — разделители `\` и `/` нормализуются, ложные предупреждения об отсутствии файлов расширения устранены.
- **Новая проверка «плоского» архива**: сборка предупреждает, если `YTShortsManager.exe` оказался во вложенной папке (это ломает обновление).
- **Проверка наличия всех обязательных файлов**: `exe`, `yt-dlp`, `ffmpeg`, `deno`, инструкция, 4 файла расширения.
- **Self-contained single-file сборка** для `win-x64` — .NET устанавливать не нужно.
- **ZIP плоской структуры**: `exe` в корне, что требуется для корректного автообновления.
- **SHA-256 выводится в конце сборки** — удобно сразу вставить в `version.json`.
