## 🚀 О программе

**YT Shorts Manager** — это полноценное десктопное приложение для скачивания видео и Shorts с YouTube. Программа имеет современный темный интерфейс, работает в системном трее, умеет обходить блокировки и обновлять сама себя.

В отличие от многих аналогов, приложение **не требует** установки Python, Node.js или дополнительных библиотек. Всё уже упаковано в один исполняемый файл.

## ✨ Основные возможности

*   📥 **Скачивание в высоком качестве**: Поддержка видео до 4K, 1080p, 720p. Всегда со звуком.
*   🧠 **Умный буфер обмена**: Просто скопируйте ссылку на видео (Ctrl+C), и программа сама вставит её в поле ввода.
*   📋 **Очередь загрузок**: Добавляйте несколько ссылок подряд, программа скачает их по очереди.
*   ✂️ **Встроенная обрезка**: Скачивайте только нужный фрагмент видео, указывая время начала и конца.
*   🎵 **Только звук**: Возможность извлечь аудиодорожку в формате MP3.
*   🌐 **Интеграция с браузером**: Скачивайте видео в один клик прямо со страницы YouTube (через встроенное расширение).
*   📜 **История и обложки**: Удобный список всех скачанных файлов с превью. Клик по видео открывает его в вашем плеере.
*   🔄 **Автообновление**: Программа сама проверяет новые версии на GitHub и обновляется в один клик.
*   🧹 **Очистка кэша**: Удаление временных файлов и истории.

## 📥 Установка и запуск

1.  Перейдите в раздел **[Releases](https://github.com/bestotarkov-max/YTShortsManager/releases/latest)**.
2.  Скачайте последний **ZIP-архив** (например, `YTShortsManager_v1.0.0.zip`).
3.  Распакуйте архив в любую удобную папку (например, на Рабочий стол).
4.  Запустите файл **`YTShortsManager.exe`**.
    *   *Если Windows покажет синее окно защиты (SmartScreen), нажмите «Подробнее» -> «Выполнить в любом случае».*
5.  Программа свернется в системный трей (возле часов). Управление доступно по клику на иконку.

> ⚠️ **Важно:** Не удаляйте файлы `yt-dlp.exe`, `ffmpeg.exe` и `deno.exe` из папки с программой. Они необходимы для работы (скачивание, звук, обход защиты YouTube).

## 🌐 Установка расширения для браузера (Опционально)

Чтобы скачивать видео в один клик прямо с сайта:
1.  Откройте браузер (Chrome, Яндекс, Edge).
2.  Введите в адресную строку `chrome://extensions/`.
3.  Включите **«Режим разработчика»** (справа вверху).
4.  Нажмите **«Загрузить распакованное расширение»**.
5.  Выберите папку `yt-bridge-extension` (лежит внутри папки с программой).
6.  Зайдите на YouTube, обновите страницу (F5). Возле кнопки «Поделиться» появится синяя кнопка ⬇️.

## ❓ Решение проблем (FAQ)

*   **Видео скачивается без звука:** Убедитесь, что файл `ffmpeg.exe` не был удален и лежит рядом с программой.
*   **Ошибка 403 или «Сбой yt-dlp»:** Нажмите кнопку **«⬆️ Обновить yt-dlp»** в программе. Разработчики `yt-dlp` часто выпускают патчи безопасности.
*   **Антивирус ругается:** Из-за того, что программа собрана самостоятельно, антивирусы (включая Defender) могут ложно срабатывать. Добавьте папку в исключения.
*   **Не работает кнопка в браузере:** Убедитесь, что программа запущена (иконка в трее) и расширение включено.
