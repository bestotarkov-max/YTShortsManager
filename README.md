# YT Shorts Manager

**Автор:** IZYXxx

Мощное приложение для скачивания и обрезки видео с YouTube (включая Shorts). 
Работает на Windows, имеет удобный интерфейс, очередь загрузок и систему автообновления.

## 🚀 Возможности
* Скачивание видео в 4K/1080p со звуком.
* Умный буфер обмена (автоматически вставляет ссылки).
* Встроенная очередь загрузок и история скачиваний.
* Обрезка видео на лету.
* Обход блокировок YouTube (через Deno).
* Автообновление до последней версии.

## 📦 Установка для пользователей
1. Скачайте последний ZIP-архив в разделе **Releases**.
2. Распакуйте в любую папку.
3. Запустите `YTShortsManager.exe`.
4. Подробная инструкция лежит внутри архива.
